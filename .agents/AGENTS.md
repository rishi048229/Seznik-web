# Project Rules & Boundaries

- **STRICT BOUNDARY**: DO NOT touch, edit, commit, or push to `seznik-web` or `main`/production branches.
- **EXCLUSIVE WORKING BRANCH**: ONLY work on, commit to, and push to the `dev` branch in `inventort-seznik` (`https://github.com/rishi048229/inventort-seznik.git`), inside the `mobile-inventory/` folder.
