# Project Rules & Boundaries

## Production Safety Rule

- **STRICT BOUNDARY**: DO NOT touch, edit, commit, or push to `seznik-web` or `main`/production branches.
- **EXCLUSIVE WORKING BRANCH**: ONLY work on, commit to, and push to the `app` branch in `inventort-seznik` (`https://github.com/rishi048229/inventort-seznik.git`) and `mobile-sez` branch in `seznik-app`.
